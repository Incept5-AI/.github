# Incept5 AI: open source

Open-source projects from **[Incept5.ai](https://incept5.ai)** (i5). Each one is its own repo with a README,
a licence and a `CLAUDE.md`, so you can clone just the project you want, start Claude Code in it, and build and
run it.

| Project | What it is |
|---|---|
| **[YuE2](https://github.com/Incept5-AI/YuE2)** | **YuE2 Studio**: full songs (vocals and backing, up to 6 minutes) generated by the YuE2-3B model natively on iPhone and iPad with Swift + MLX, with writing help from Apple's on-device model. 17 singer and instrumental presets, measurements, and what we tried and rejected. [▶ Listen to samples](https://incept5-ai.github.io/YuE2/samples/) |
| **[Private Pocket](https://github.com/Incept5-AI/private-pocket)** | **A local-first iPhone app for the [Pocket](https://heypocket.com) voice recorder**: talks to the card directly over Bluetooth to record, stream live, sync, transcribe, label speakers, summarise and answer questions, with nothing sent to Pocket's cloud. Runs fully on-device (Apple `SpeechAnalyzer` + Apple Intelligence) or on a server you choose. Includes the documented Bluetooth protocol and Mac tools. |
| **[languages-benchmark](https://github.com/Incept5-AI/languages-benchmark)** | Two coding benchmarks for LLMs (48 and 120 tests) in Python, Java, Swift, TypeScript, C and Rust, run against any OpenAI-compatible endpoint. Every test has a verified reference solution in all six languages; reports include heat maps by language and challenge. [▶ Example results](https://incept5-ai.github.io/languages-benchmark/docs/example-report.html) |
| **[HLE Lite](https://github.com/Incept5-AI/hle-lite)** | 173 hard multiple-choice questions from the audited Gold subset of Humanity's Last Exam, graded by exact answer letter with no LLM judge. Built for deciding between models: paired McNemar tests tell a real difference from noise. Includes example runs on DGX Spark, Mac and Tenstorrent. [▶ Example results](https://incept5-ai.github.io/hle-lite/docs/example-report.html) |

Licences differ per project, so check each repo's `LICENSE`. YuE2 is non-commercial (CC BY-NC 4.0) because
the model weights are. Private Pocket is MIT; languages-benchmark and HLE Lite are Apache-2.0.

Questions and contributions are welcome: open an issue or a pull request on the project.
